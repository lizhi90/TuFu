## M1 EtherCAT 从站到 OP（**最关键一步**）

**步骤**
```bash
ethercat slaves                 # 列出 SV630
ethercat slaves -v              # 记录 Vendor/Product/Revision  ← 填入下方记录表
ethercat sdos 0 > sdo.txt
ethercat pdos 0 > pdo.txt
ethercat cstruct > cstruct.txt  # ★ 后续代码直接用
ethercat upload 0 0x6060 0x00   # 看上电默认模式
ethercat states 0 OP            # 尝试进 OP
```

**通过判据（✅ 已通过，详见 `03` §7）**
- [x] `ethercat slaves` 状态 `OP`（Vendor `0x00100000` / Product `0x000c0112`），`ethercat master` 无 AL 错误
- [x] 真实 PDO：SM2=`{6040:16,607a:32,6060:8}`(7B) / SM3=`{6041:16,6064:32}`(6B)
  （⚠️ SII 默认 12/28 存疑，已用 `--explicit` + 精确 `vendor_id/product_code`）
- [x] DC 正常（SYNC0 1ms，`assign_activate=0x0300`），进 OP 且 1ms 周期 **12000/12000 零丢拍**

**若进不了 OP**：先 `states 0 PREOP` → 单独配 DC 排查 → 或临时 `assign_activate=0` 验证基础链路。

## M2 单轴基础运动（PP 模式，先命令行验证）

**步骤（`tools/ecat_axis.cpp` 已实现，实机脚本见 `deploy/36~40`）**

2. ✅ 使能序列：`6040 = 0x80 → 0x06 → 0x07 → 0x0F`，观察 `6041` 位变化（`37-m2-verify.sh`）。
3. ✅ 定位：写 `6081/6083/6084`、`607A`、`6040 |= 0x10`，判 `6041.bit10/bit12`（`38-m2-move.sh`）。
4. ✅ 点动：切 `6060=3(PV)`，写 `60FF=±v`，`60FF=0` 停（`40-m2-jog.sh`；60FF 走 SDO 避开档位3 被拒）。
   实测 `6061=3`、`60FF=±70217 inc/s`，正/反向各 ≈9.49mm/2s 且减速停稳。
5. ✅ 急停：`6040.bit8=1`（`40-m2-jog.sh 5 2 estop`）。强验证：保留 `60FF` 只靠 halt，
   停止距离 0.0152mm、残余漂移 0.0000mm、`cw=0x010f`。
6. ✅ 核对 `INC_PER_MM`：命令 5mm 实测 4.9999mm，链路自洽；与旧 `PULSE_EQUIV` 一致，**保持 14043.41**
   （绝对标定 `100mm→实测m` 属现场工装，见 `04` §1.1、`deploy/39-m2-unit.sh`）。
7. ✅ 停机语义实读：`41-m2-sdo-stop.sh` 读到 `605A=2 / 605D=1 / 605C=0 / 6085=2147483647`，
   与手册默认**完全一致** → `6040.bit8`(halt) 按"减速停"执行（由 **`605D`** 决定，与 `605A` 无关）。
8. ✅ 急停响应时间：`42-m2-estop-time.sh` 多速度跑 `--estop`，v0=1mm/s → **9.0ms**、v0=5mm/s → **13.0ms**

### 最小程序（增量2 已实现：`tools/ecat_probe.cpp`）

只做"上总线 + 1ms 循环 + 打印 PDO 实读值"，**不使能**（`6040=0`），上板即可验证 PDO 偏移与 DC。

```bash
cd /home/ubuntu20/Kine-X/lubancat2
mkdir -p build && cd build
cmake .. && make -j4

# 基础链路（关 DC）：先确认能激活、状态字有值
sudo ./ecat_probe 10 --dc 0
# 开 DC（SYNC0 1ms, shift 0.5ms）
sudo ./ecat_probe 10
# 默认映射不含所需对象时，改用手工精简映射
sudo ./ecat_probe 10 --explicit
```

输出应看到 `sw=0x...`（非 0）、`mode=...`、`pos_actual/pos_demand` 稳定；`抖动` 应接近 0。
若 `slave_config` 失败 → 用 `ethercat slaves -v` 的 ID 加 `--vid/--pid`；
若注册 PDO 失败 → `ethercat cstruct` 核对对象，或加 `--explicit`。

### 主程序（增量5 已实现：`src/main.cpp`，需 IgH）

装配 `EthercatMaster` + `Axis` + `Shared`，跑 1ms RT 循环
（`receive → 读 TxPDO → axis.tick → 写 RxPDO → send`），并把 6081/6083/6084
交给独立 SDO 线程下发（ecrt SDO 会阻塞，不能放 RT 线程）。**控制器进程不含任何协议服务**，
可用 §3 的命令行验证，或临时写个小程序向 `Shared` 投递 `AxisCmd`；协议对接由脚本线程承担
（`SCRIPT_ENABLE=1`，见 `08`/`10`，协议基准见 `05`）。

```bash
cd /home/ubuntu20/Kine-X/lubancat2/build
cmake .. && make -j4

sudo ./kine-x --dump              # 只看解析后的配置，不碰总线
sudo ./kine-x                      # 用 config/app.conf 启动
sudo ./kine-x ../config/app.conf --dc 0        # 关 DC 先验基础链路
sudo ./kine-x --explicit --cpu 3 --prio 80     # 强用精简 PDO 映射
```

期望：
- 启动打印 `[ecat] 已激活 ... PDO 偏移: cw=.. tp=.. ...`；
- 进入 OP 后打印 `[rt] EtherCAT 进入 OP`；
- 每 3s 一行 `[stat]`，其中 `bus=OK`、`cyc` 持续增长、`jit` 在 RT 内核下应 < 100us；
- `Ctrl-C` 后打印 `[rt] 已退出 ... 最大抖动 ..us`，驱动器卸力（6040 回 0x06）。

> ✅ 取值已定：生产用 `--explicit`（`ECAT_EXPLICIT_PDO=1`）+ 精确 `vendor_id/product_code`；
> `--dc 0` 仅用于激活自检（`0x1c32:20=1` 要求 SYNC0，见 `03` §7）。

## M6 上线与回退

**上线**：`systemctl enable --now kine-x`；确认断电重启后自动进 OP 并恢复业务；并确认**调试口 5000 已监听业务网**（局域网 PC 的 VSCodium 插件可直连，见 `13` §4.3/§4.5）。

**回退（保留旧控制器，一键切回）**
1. 业务网线插回原 ZMC，PC/触摸屏/机器人/网关 IP 不变。
2. 断开鲁班猫2 的 EtherCAT 与业务口（避免双主站/双服务）。
3. 原 ZMC 上电即按原逻辑运行。

> ⚠️ **绝不允许同时有两台设备做同一角色的主站/服务端**（双 EtherCAT 主站会冲突；
> 双 502/4321 服务端会 IP 冲突）。回退前先断鲁班猫2。
