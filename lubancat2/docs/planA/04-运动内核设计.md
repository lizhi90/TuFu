# 04 运动内核设计（单轴）

> 对应原任务0的功能：总线初始化、使能、急停、点动、点到点定位、状态查询。
> 本模块是**唯一需要实时**的部分：1ms 周期，绑核 CPU3，`SCHED_FIFO 99`。

---

## 1. 单位换算（务必与旧系统一致）

旧系统：`units(0) = PULSE_EQUIV = 14043.41`，即 **1 mm = 14043.41 脉冲**，`MPOS/DPOS` 直接是 mm。

新系统定义（`config/app.conf`）：

```
INC_PER_MM = 14043.41     # = 旧 PULSE_EQUIV，与正运动 0x607A 逐位一致（M2 已核对）
```

- `inc  = mm  * INC_PER_MM`（`mm_to_inc` 用 `llround` 四舍五入，同 `axis_test`）
- `mm   = inc / INC_PER_MM`
- 换算**只在控制器侧做一次**，与旧系统 `units(0)=PULSE_EQUIV` 语义等价：正运动把
  `MOVEABS(mm)` 在内部换算成「脉冲」后写入 `0x607A`；C++ 侧直接算 `607A = mm*INC_PER_MM`。

### 1.1 M2 实机核对结论（2026-09-23）

| 项 | 结果 |
|----|------|
| 命令 +5.000mm | `0x607A` 增量 = 5.000×14043.41 = **70217** |
| 实测位移 | `0x6064` 换算 = 5.0123 − 0.0124 = **4.9999mm**（相对误差 ≈ 0.002%） |
| 链路自洽 | `mm → 607A → 6064 → mm` 无累积误差 ✅ |
| 与旧系统一致 | C++ `INC_PER_MM` = 旧 `PULSE_EQUIV` ⇒ 下发 `0x607A` 与正运动**逐位相同**；SV630 参数未改 ⇒ 物理运动一致 ✅ |

**驱动器侧对象实读**（`deploy/39-m2-unit.sh`）：

- `0x6091:01=1`、`0x6091:02=1` → 电子齿轮比读回 **1:1**；
- `0x6092`（进给常数）、`0x608F`（编码器分辨率）、`0x6093/0x6094/0x60C2` **均不存在**
  （abort `0x06020000`/`0x06010000`）→ 无法仅由对象字典反推「用户单位/mm」。

> **判定**：`INC_PER_MM = 14043.41` **保持不变**。理由：
> ① 它是旧系统 `PULSE_EQUIV` 的正式标定值（早期调试脚本 `EtherCAT.txt` 曾用 `16770`，后统一为 14043.41）；
> ② 只要新旧系统同值且 SV630 参数不变，二者位移必定相同，对外「零改动」成立；
> ③ 物理绝对精度由机械（丝杠导程/减速比）决定，**属现场工装标定，与控制器迁移无关**。

**现场绝对标定方法（待工装）**：命令走 100.000mm，用卷尺/百分表量实测 `m`，
`INC_PER_MM_new = 14043.41 × 100 / m` 写回 `config/app.conf`。若 `m` 与 100 相差 > 0.5%，
先核对驱动器电子齿轮比与丝杠导程，再决定改控制器还是改驱动器。

### 1.2 `datum(0)` 语义（已定案，无位置清零副作用）

旧程序启动序列含 `datum(0)`（`EtherCAT_SocketServer.bas:401`，注释"清除控制器错误"）。

**ZBasic 手册原文证据**（`ZBasic编程手册V3.3.0.pdf`，已抽出文本 `pdf_out/example_tcp_plumber.txt`）：

- `example_tcp_plumber.txt:399` → `DATUM(0) '清除控制器所有轴错误`
- `example_tcp_plumber.txt:436` → `DATUM(0) '清除控制器错误`（RTEX 例程，紧跟在 `DRIVE_CLEAR(0)` 之后）
- `example_tcp_plumber.txt:538` → 故障排查流程图："用在线命令输入 `DATUM(0)` 清除错误后重新排查"
- 对照：**回零**另有写法 `DATUM(3) AXIS(0) '实际设备轴0的归零`（`:227`）

**结论**：`DATUM(0)` 中 `0` 是**模式选择**（=清除控制器所有轴错误），不是轴号，**不改变坐标**；
真正的"当前位置置零"是 `DATUM(3) AXIS(n)`。故旧系统上电后 `MPOS` **同样**从编码器绝对零点起，
与本 C++ 侧（实测使能瞬间 `mpos=0.0124mm` = 174 inc）**无差异**，屏显 `MPOS` 绝对值一致。

**副作用**：无。已实现的 `6040=0x80`（fault reset）承担旧 `DATUM(0)` 的"清错误"职责。

**脚本引擎落地**（`08`）：`DATUM(0)` 在 `ScriptHost` 中**显式接受并返回 0**（不再是"未知命令→静默退化为
数组访问"）；`DATUM(3)`=**当前位置置零**已落地——内核新增 `AxisCmd::SET_POS`，通过在 `Axis` 内维护
**坐标系偏移** `pos_offset_inc_`（用户 mm = `(inc - 偏移)/inc_per_mm`）实现"不动电机、只改坐标基准"，
`POS`/`DPOS` 及定位目标/到位判定均随偏移；其余模式未定案，**明确报运行错误**。

**`HOME`**：脚本引擎侧已实现为**软件回零**（`AxisCmd::HOME` = 绝对定位到 `AxisConfig::home_mm`，默认 0）；
绝对编码器系统下即"回到机械零点"。驱动器内部回零（`6060=6` + `0x6098` 回零方式）仍待 `0x6098` 定案，
属驱动器侧独立后续项（见 `08` §8.4）。

## 2. CiA402 状态机与使能序列

沿用旧系统的 `DRIVE_CONTROLWORD: 128 → 6 → 15`，并补上状态位等待（更稳）：

```
① 清故障: 6040 = 0x80 (128)          // fault reset
② 关机:   6040 = 0x06 (6)            // shutdown, 等 6041.bit0(ready to switch on)
③ 开机:   6040 = 0x07 (7)            // switch on, 等 6041.bit1(switched on)
④ 使能:   6040 = 0x0F (15)           // enable operation, 等 6041.bit2(op enabled)
⑤ 就绪:   6041.bit2=1 且 bit3=0(fault)
```

- 去使能（旧 `DIS;`）：`6040 = 0x06`（回 shutdown），并置应用层 `wdog=0`。
- 报警清除（旧 `RCLEAR` 的伺服侧）：`6040 = 0x80`。
- **看门狗**：`ecrt_slave_config_watchdog(sc, 0, 0)` 关闭或用默认，避免误断使能。

## 3. 三种运行模式（M2 先 PP，M3 视需要上 CSP）

### 3.1 PP —— 轮廓位置模式（**首选，实时压力最小**）

点动以外的定位全用它；主机只写参数一次，运动由驱动器执行。

| 步骤 | 对象 | 值 |
|------|------|----|
| 设模式 | `0x6060` | `1` (PP) |
| 速度 | `0x6081` | 速度(inc/s) |
| 加/减速 | `0x6083`/`0x6084` | inc/s² |
| 目标位置 | `0x607A` | 绝对/相对位置(inc) |
| 触发 | `0x6040` | `0x0F \| 0x10(bit4=new setpoint)`；相对置 bit6；立即置 bit5 |
| 完成判据 | `0x6041` | bit12(setpoint ack)=1 且 bit10(target reached)=1 |

- 对应旧 `MOVEABS/MOVE`：绝对 = bit6 清 0；相对 = bit6 置 1。
- 运动中重复命令 → 应答 `busy`（同旧逻辑）。

### 3.2 PV —— 轮廓速度模式（点动）

| 步骤 | 对象 | 值 |
|------|------|----|
| 设模式 | `0x6060` | `3` (PV) |
| 加/减速 | `0x6083`/`0x6084` | inc/s² |
| 速度 | `0x60FF` | 有符号 inc/s（正负=方向） |
| 停止 | `0x60FF=0` 或 `0x6040.bit8(halt)` | 按减速曲线停 |

- 对应旧 `VMOVE(±1)/CANCEL(2)`；点动速度换算同 `INC_PER_MM`。

**本工程实现要点（`tools/ecat_axis.cpp`，已 M2 实机验证 PASS）**

- `0x60FF` 在 SV630 真实 PDO 里**未映射**：档位1/2 的 `0x1600` 只有 `{6040,607a,6060}`；档位3 追加 `60FF/6062` 实测被拒（AL `0x001E`，见 07 §7）。
- 因此 PV 点动采用：**模式/控制字走 PDO，`0x60FF` 走 SDO**（值变化才下发，见 `tools/ecat_axis.cpp::sdo_thread`）。
- 进入 PV 前必须等 `0x6061==3` 回显确认，故 **PDO 档位必须 ≥2**（档位2 才有 `6061`）。
- RT 线程仍按无阻塞原则：只 `want_mode_=3` + 写 `6040`；SDO 由独立线程串行下发。
- 停机：正常点动结束用 `0x60FF=0` 走减速曲线；急停用 `0x6040.bit8(halt)`。
- 实测（07 §8.4）：`60FF=±70217 inc/s(±5mm/s)` 正/反向各 ≈9.49mm/2s；
  保留 `60FF` 仅靠 halt 停车 → 停止距离 0.0152mm（halt 可独立压过速度环）。

### 3.3 CSP —— 循环同步位置（✅ M3 已实施，2026-09-27）

| 步骤 | 对象 | 值 |
|------|------|----|
| 设模式 | `0x6060` | `8` (CSP) |
| 每周期 | `0x607A` | 目标位置(inc)，由梯型规划器给出 |
| 位置源 | `0x6064` | 实际位置回读 |

**实施记录（2026-09-27，真机验证通过）**：

- **PDO 复用档位1**：SV630 档位1 的 RxPDO 本就含 `{6040, 607A, 6060}`——CSP 所需对象全部就位，无需改档位；Tx 用 6041/6064 监测。
- **Axis 内核**（`motion/axis.{h,cpp}`）：`csp_mode_`（config `MOTION_MODE=pp|csp` 初始化 / 脚本 `MOTION_MODE(0|1)` 运行时切换）；`start_move` 在 CSP 下改用内置 `Trapezoid`（`motion/interp.h`）规划，`tick` MOVING 子模式 `Sub::SELF` 每拍输出 `traj_.step(1ms)` 到 607A；**完成判定 = 规划完成 + 实际位置进容差**（不用 6041.bit12/bit10，CSP 下无 setpoint 握手）；STOP 时 `traj_.abort_at(actual)` 对齐。
- **DC 同步**：`ECAT_DC_ASSIGN=0x0300`（SYNC0 1ms）真机启用成功；CSP + dc_assign=0 时启动告警。
- **真机验证**：`MOTION_MODE=csp` 下 4321 `1;` → `move_done`、MPOS=DPOS=1.000；`0;` 回程双 0.000。验证后现场已恢复 `MOTION_MODE=pp`（csp 通路保留，按需切换）。
- **回归**：`axis_test` 新增用例 14/15（CSP 定位渐进输出+到位、CSP STOP 对齐）；板上 aarch64 环境测试 ALL PASS。

### 3.4 多轴直线插补（✅ 2026-09-27 实施）

- **插补器**（`motion/interp.h`，纯逻辑）：`LinInterp` 生成共享进度 s(t)∈[0,1]（主导轴=|dist| 最大者承受 speed/accel，梯形/三角形自动），位置_i = start_i + dist_i·s(t)——**所有轴共用同一 s，路径严格为直线**。
- **会话链路**：脚本宿主写 `Shared::lin`（LinReq：轴表/目标/speed/accel）→ RT 每拍受理（校验使能/总线/空闲）→ 每拍 `csp_feed(target_inc)` 逐轴下发 → 到点后 100ms 容差确认 → state=3 done / 4 error（含中止传导：任一轴故障/急停/掉线即整组中止）。
- **脚本用法**（对齐 ZMC 习惯）：
  ```lua
  MOTION_MODE(1)        -- 切 CSP（插补要求；PP 下各轴时间归一近似）
  BASE(0, 1)            -- 轴表
  MOVEABS(10, 20, 100)  -- 轴0→10、轴1→20 直线插补，主导速度 100mm/s（阻塞）
  BASE(0)               -- 回单轴
  ```
- **真机验证**：多轴插补需 ≥2 轴硬件，本站单轴暂无法实机验证（逻辑由 `interp_test` 6 组数学断言 + `motion_host_test` LIN 请求/拒绝/失败路径覆盖）；单轴 LIN 等价于 CSP 定位（已真机验证）。
- **回归**：`interp_test`（新）+ `motion_host_test` 用例 7；ctest 16/16。
- **未做（2026-09-27 拍板，见 planA README §五.5）**：**圆弧插补（MoveC 类）暂不实施**——将来有连续轨迹需求时，在 `LinInterp` 基础上扩展参数化路径（同框架把 s(t) 的线性映射换成弧长映射），规划与 DC/CSP 链路全部复用。

## 4. 梯型（可扩展 S 曲线）位置规划器

仅 CSP 需要；PP/PV 下驱动器自带规划。接口：

```cpp
struct Profile {
    double start, target;      // inc
    double vmax, amax, dmax;   // inc/s, inc/s^2
    double v, p;               // 当前速度/位置
    int    dir;                // +1/-1
    bool   done;
    void   reset(double p0, double tgt, double vmax, double acc, double dec);
    double step(double dt);    // 返回本周期目标位置
};
```

- 加速段 → 匀速段 → 减速段；`step(0.001)` 每 1ms 调用一次。
- 完成条件：`|p - target| < tol` 且 `v ≈ 0`。
- 停机/急停：把 `amax` 设为最大并按 `dmax` 减速到 0，或直接 `6040.bit8=1`。

## 5. RT 主循环（伪代码）

```cpp
// 绑核 + SCHED_FIFO 后进入
while (running) {
    ecrt_master_receive(master);
    ecrt_domain_process(domain);

    // 1) 读 TxPDO -> 共享状态
    status->sw      = EC_READ_U16(tx_statusword);
    status->pos_inc = EC_READ_S32(tx_pos_actual);
    status->mpos    = status->pos_inc / INC_PER_MM;
    status->dpos    = EC_READ_S32(tx_pos_demand) / INC_PER_MM;
    status->idle    = (status->sw & 0x0400) ? 1 : 0;   // bit10 target reached
    status->fault   = (status->sw & 0x0008) ? 1 : 0;   // bit3 fault
    status->bus_ok  = 1;

    // 2) 取非RT线程下发的命令(加锁队列), 执行状态机/模式切换/写目标
    motion_tick();      // 使能序列/PP触发/PV速度/CSP规划 -> 写 RxPDO

    // 3) 写 RxPDO
    EC_WRITE_U16(tx_controlword, cmd->cw);
    EC_WRITE_S32(tx_target_pos,  cmd->target_inc);
    EC_WRITE_U8 (tx_mode,        cmd->mode);

    // 4) DC 同步
    ecrt_master_application_time(master, t_ns);
    ecrt_master_sync_reference_clock(master);
    ecrt_master_sync_slave_clocks(master);

    ecrt_domain_queue(domain);
    ecrt_master_send(master);
    clock_nanosleep_abs(next_tick);      // 1ms 绝对唤醒
}
```

## 6. 与旧系统的语义映射表

| 旧 ZBasic | 新实现 | 备注 |
|-----------|--------|------|
| `AXIS_ENABLE=1; wdog=1` | 6040 序列 6→7→0F | `wdog` 仅应用层软开关 |
| `DIS;` → `wdog=0; AXIS_ENABLE=0` | 6040=0x06 | — |
| `MOVEABS(pos) AXIS(0)` | PP: 6060=1, 607A=pos*INC_PER_MM, 6040\|bit4(绝对) | 应答 `OK/n` |
| `MOVE(dist) AXIS(0)` | PP: 同上，相对置 bit6 | — |
| `VMOVE(±1) AXIS(0)` | PV: 6060=3, 60FF=±spd*INC_PER_MM | 点动 |
| `CANCEL(2)` | PV: 60FF=0 | 点动停止 |
| `RAPIDSTOP(2)` | 6040.bit8=1（halt） | 急停；停机方式由 **`605Dh`**（默认 1）决定，与 `605Ah` 无关 |
| `SPEED/ACCEL/DECEL` | 6081 / 6083 / 6084 | 单位换算后下发 |
| `MPOS(0)` | 6064 / INC_PER_MM | mm |
| `DPOS(0)` | 6062 / INC_PER_MM | mm |
| `IDLE(0)!=0` | 6041.bit10=1 且速度≈0 | 到位判据 |
| `AXISSTATUS & MV_ERRMASK` | 6041 位 + `203F` 唯一错误码映射 | 见下；`603F` 会重复，仅供粗判 |

### 报警位映射（形成 `MV_ERRMASK` 等价物）

| 旧位 | 含义 | 新来源 |
|------|------|--------|
| 8 驱动器 | 驱动器报警 | `6041.bit3` fault |
| 4 通讯 | 总线断/无 DC | IgH AL Status / `bus_ok=0` |
| 16/32/512/1024 | 硬/软限位 | `6041.bit7`(warning) / 驱动器限位位 |
| 其余 | 随动/超频/电源等 | `203F` 唯一错误码（见手册 md §14/§16）；`603F` 会重复不可作唯一键 |

> 应用层只需暴露一个 `alarm` 布尔 + `err_code`，供 502 的 `4x3`（状态码=4 报警）与 4321 的 `move_error` 使用。

## 7. 非 RT 线程接口（共享状态）

```cpp
struct AxisStatus {   // 读
    int    bus_ok, idle, enabled, alarm;
    double mpos, dpos;
    int    err_code;
};
struct AxisCmd {      // 写(仅设置一次, 由RT消费)
    enum { NONE, ENABLE, DISABLE, MOVE_ABS, MOVE_REL, JOG, STOP } op;
    double pos, speed, accel;
};
```

- 用 `std::mutex` 保护（RT 侧只做极短加锁）或用无锁/双缓冲。
- 4321/502 服务线程通过该结构下发命令、读取状态。
