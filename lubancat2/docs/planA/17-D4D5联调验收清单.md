**打通前置（EtherCAT 设备权限，一次性）**——`/dev/EtherCAT0` 默认仅 root 可访问，
服务以 `cat` 用户运行会 `Permission denied` 启动失败（journal 关键词）：

```bash
echo 'KERNEL=="EtherCAT[0-9]*", MODE="0660", GROUP="realtime"' | sudo tee /etc/udev/rules.d/99-kine-x-ethercat.rules
sudo chgrp realtime /dev/EtherCAT0 && sudo chmod 660 /dev/EtherCAT0
sudo systemctl restart kine-x
```
