# 18. 触摸屏寄存器总表（502 Modbus-TCP 从站，4x 区）

> 面向屏（HMI）的**单一事实来源**：控制器 502 从站（站号 1）4x 保持寄存器全量清单。
> **502 为多客户端（2026-09-28）**：触摸屏与机器人（Modbus 主站）可**同时**连接同一 502；
> 触摸屏用 0~255 区，机器人用 **1000~1199 区**（规划见 `planA/19`）——同一张寄存器表、各自读各自的地址段。
> 实现位置：`EtherCAT_SocketServer.lua`（脚本自解析 MBAP/PDU，03/04 同读区、06/16 写）。
> 分区详表另见：机器人 `planA/05 §4.5`、称重 `planA/05 §1` 与根《称重…笔记》、蠕动泵 `planA/05 §8` 与根《蠕动泵…笔记》§0。
> 本文按**地址顺序**汇总，屏端配置一律以本表为准；未列出的地址为空闲（新功能另行分配，勿占用）。

## 0. 通用约定（配屏前必读）

| 约定 | 说明 |
|---|---|
| 地址 | 表中 `4xN` 即 4x 区 0 基地址 N；32 位浮点占 **N/N+1 两格**（`N`=低字、`N+1`=高字） |
| 浮点字序 | **低字在前（CDAB：字交换、字内大端）**（与旧 ZMC `MODBUS_IEEE` 一致；机器人 Modbus 区同款）；泵侧浮点为高字在前，脚本已转换 |
| 寄存器内字节序 | big-endian（标准 Modbus） |
| 按钮类写法 | 用「**写常数**」按钮：命令码写 1~6 即触发（重复写同值也可），控制器处理完**自动回 0**；触发位（成对/点动）按 0→1 沿或 1→0 沿 |
| 「写即触发」寄存器 | 4x30（校准提交）、4x203（泵命令码）、4x213（圈数运行）、4x219（回吸提交）、4x229（容积运行）——写非 0 即执行、完成自动回 0 |
| 掉电保持（控制器 `.nvram`） | **4x64/65、69/70、71、72、73、130/131、132/133、204、211/212、214、221/222、225/226**：控制器持久化到脚本目录 `.nvram`，开机（脚本 init）自动恢复；写入即落盘（原子写）。清单=脚本 `NVRAM_REGS` |
| 掉电保持（设备内） | **4x215/217**（回吸角度/速度）：值存于**泵内**（掉电存储），上电后控制器自动读回显示；**4x122~129/136 等称重参数**：校准与标定存于**称重模块内** |
| **不保持**（重启回默认/零） | 其余所有 HMI 设定：4x28~31 校准计数、4x60~63/66~68 轴命令与目标、4x140~201 机器人运行态、4x202/203/205~210/213 泵运行中间态等 —— 掉电/重启后需重新设置 |
| 类型标注 | `int16`/`uint16` = 单寄存器；`float32` = 两寄存器低字在前 |

## 2. 折线校准区（说明：模块=称重变送器 0x0017/0x0018/0x0006 等，见称重笔记 §4.4）

| 地址 | 读写 | 类型 | 说明 |
|---|---|---|---|
| 4x28 | 写 | int16 | 校准点重量输入（**十进制整数、不带小数点：最小 1g 输 1，10g 输 10**）；提交时按比例系数（4x132/133，默认 ×100）换算为模块计数 |
| 4x29 | 读 | int16 | 已提交点数（0~10） |
| 4x30 | 写 | int16 | **1 = 提交当前点**（首次自动关写保护 + 设 10 点折线；满 10 点后再提交有效重量=自动开始新一轮）；**2 = 重置计数**；处理完自动回 0 |
| 4x31 | 读 | int16 | 结果码：0 空闲 / 1 成功 / 2 重量无效 / 3 已满（仅无效重量时）/ 4 未连接 |

| **4x75** | 写 | **int16** | **轴使能按钮**（2026-09-29）：写 1 触发（上升沿/写即触发，处理完自动回 0）；**安全联锁（机器人急停 4x145）期间或总线未就绪时拒绝并日志**（4x147 故障不参与联锁，2026-09-29 晚）；使能状态读 4x3 状态码（≥2=已使能） |
